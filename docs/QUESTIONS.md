# 计分模型

## 胜完四维

- **W1** 小太阳 / DJ
- **W2** 感性人格 / 音乐人
- **W3** 温柔学霸 / 牙医
- **W4** 理性工作狂 / 娱乐公司老板

## 柱现四维

- **I1** 花店老板
- **I2** 职场精英
- **I3** 画家
- **I4** 幼儿园老师

## 计分规则

每题四个选项都对应一组分数：

- 主人格：**+2**
- 次人格：**+1**
- 其余：**+0**

这样每题都能拉开差距，但又保留一点混合感。

# 平分时怎么处理

为了避免出现并列，建议你这样定：

## 胜完平分优先级

看这些“定锚题”：

- W1 锚题：Q1 / Q5 / Q10
- W2 锚题：Q3 / Q8 / Q11
- W3 锚题：Q4 / Q6 / Q9
- W4 锚题：Q2 / Q7 / Q12

谁在对应锚题里得分更高，谁胜出。

## 柱现平分优先级

- I1 锚题：Q13 / Q16 / Q24
- I2 锚题：Q14 / Q18 / Q23
- I3 锚题：Q17 / Q20 / Q21
- I4 锚题：Q15 / Q19 / Q22
